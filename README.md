# Shyamkumar Nahate – Software Portfolio

Static portfolio site (single `index.html`, no build step).

## Host on GitHub Pages
1. Create a new repository named `Software-Portfolio` (the name is case-sensitive in the site address).
2. Upload `index.html` and `README.md` to the repository root.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. Your site goes live in about a minute at `https://shyam06040.github.io/Software-Portfolio/`.
